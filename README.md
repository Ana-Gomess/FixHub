# FixHub

MVP para registrar e acompanhar avarias em hoteis.

## Funcionalidades
- Cadastro de avaria com local, categoria, prioridade, responsavel e descricao.
- Painel com ocorrencias abertas, em andamento e resolvidas.
- Filtros por status.
- Atualizacao de status ao clicar na etiqueta da ocorrencia.
- Dados persistidos no navegador para demonstracao sem servidor.

## Roteiro de demonstracao
1. Mostrar o painel de ocorrencias.
2. Clicar em Registrar avaria e cadastrar um problema de quarto.
3. Mostrar a nova ocorrencia como aberta.
4. Clicar no status para passar para Em andamento e Resolvida.
